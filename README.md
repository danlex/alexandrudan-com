# Alexandru DAN - Personal Website

Static personal website for Alexandru DAN, CEO at TVL Tech.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

## Local preview

Run a static server from this directory, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy

Push to `main` and publish with GitHub Pages from the repository root.
